# 🚗 Car Price Prediction with Machine Learning

Predicting car selling prices using machine learning regression models. This project includes exploratory data analysis, data visualization, feature engineering, model comparison, and performance evaluation.

## 📊 Dataset

The dataset contains **301 car records** with information about vehicle prices, mileage, fuel type, transmission, ownership, and other characteristics.

**Source:** [Car Price Prediction Dataset – Kaggle](https://www.kaggle.com/datasets/bhavikjikadara/car-price-prediction-dataset)

## 🛠️ Technologies

- Python
- Pandas & NumPy
- Matplotlib
- Scikit-learn
- Joblib

## 🤖 Machine Learning Models

Four regression models were evaluated using 5-fold cross-validation:

- Linear Regression
- Decision Tree Regressor
- Random Forest Regressor
- Gradient Boosting Regressor

## 📈 Model Performance

**Best Model: Gradient Boosting Regressor**

| Metric | Test Result |
|---|---|
| R² Score | 0.968 |
| MAE | 0.564 |
| RMSE | 0.860 |

Price errors are measured in INR lakhs. These results are based on a small historical dataset and do not establish performance on current market data.

## 🔮 Future Improvements

Develop an interactive Streamlit application.
Integrate more recent vehicle market data.
Improve predictions with additional vehicle features.
